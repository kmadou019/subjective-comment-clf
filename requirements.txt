# Direct dependencies of rag/ (the only pipeline shipped on main/dev).
# Only top-level imports are pinned; pip resolves transitive dependencies
# (torch, transformers, pillow, aiohttp, starlette, ...) at install time,
# which keeps them on currently-maintained, patched releases instead of
# freezing a two-year-old dev environment's full `pip freeze`.
#
# The previous requirements.txt was a full `pip freeze` (182 packages)
# that pulled in unused SDKs never imported anywhere in this repo
# (boto3, google-cloud-*, kubernetes, mistralai, openai, langchain-aws,
# langchain-google-vertexai, langchain-mistralai, langchain-openai...).
# Those accounted for most of the Dependabot alerts; removing them
# removes the alerts with them instead of just bumping versions.
#
# Known residual Dependabot/OSV flags on the versions below, judged not
# applicable to how this code actually uses these libraries:
#   - chromadb: auth/RBAC/multi-tenancy CVEs in the Chroma *server*.
#     We only ever use chromadb.PersistentClient (local, embedded, no
#     server, no network, no auth) — see rag/chroma.py, rag/graph_builder.py.
#   - langchain-core / langchain / langgraph: SSRF in ChatOpenAI token
#     counting, path traversal in load_prompt()/file-search loaders,
#     unsafe checkpoint deserialization. This repo never uses ChatOpenAI,
#     load_prompt(), document loaders, or LangGraph checkpointing.
#   Fixing these for real requires the 1.x majors of langchain-core/
#   langchain/langgraph, which are breaking changes beyond a version
#   bump (import paths, deprecated interfaces) — do that as a deliberate
#   migration, not part of a dependency-security pass.
